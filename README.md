# DadaDevourer

Production-grade security testing platform foundation.

## Stack

- Frontend: Next.js + TypeScript
- API: FastAPI + Python
- Database: PostgreSQL
- Queue/cache: Redis
- Containerization: Docker Compose

## Phase 1

Phase 1 establishes the application structure, health endpoints, authentication foundation, target management, and an authorized web security headers scanner.

> Only scan systems you own or have explicit permission to test.
